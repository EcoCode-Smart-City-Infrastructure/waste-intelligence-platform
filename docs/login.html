No account yet? Create one with your email.

Accounts created here live in this browser only (localStorage, password stored as a SHA-256 hash, never in plain text). They do not travel between devices and no verification email is sent — this is demo-grade local auth, not a server account system. Do not reuse a real password here. For shared, server-verified accounts, connect Firebase Auth, Auth0, or Supabase in auth-config.js.

In the meantime, create a local email account — that path works today, in this browser.
